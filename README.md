## Overview

The **Kindred Web Platform** serves two critical roles:

1.  **The Professional Portal:** A comprehensive dashboard for Fitness Trainers and Nutritionists to manage clients, view synced health data, and create personalized wellness plans.
2.  **The API Backend:** A robust Next.js server that powers the mobile app, handling authentication, complex matching algorithms, and health data aggregation.

Built with **Next.js 16 (App Router)** and **Supabase**, it ensures real-time data synchronization and secure, scalable performance.

---

## Technical Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Database & Auth:** Supabase (PostgreSQL + Auth)
- **Styling:** Tailwind CSS v4
- **Deployment:** Coolify
- **Security:** Row Level Security (RLS) + Server-Side Auth

## Key Features & Implementation

### 1. Professional Dashboard

The command center for wellness professionals.

- **Client Management:** Professionals can view their roster of matched clients (`/professionals/clients`).
- **Health Insights:** Visualizes high-fidelity health data (steps, calories, macros) synced from clients' Apple HealthKit via the mobile app.
- **Plan Creation:** Tools to assign specific exercise and nutrition plans to clients.
- **Direct Messaging:** Integrated chat to communicate with clients, answer questions, and provide feedback in real-time.

### 2. The Matching Engine (`/api/me/match`)

The intelligence behind the connection, powered by **NVIDIA NIM**.

- **The Pipeline:**
  1.  **Ingestion:** When professionals update their bios, a Supabase Edge Function triggers **NVIDIA's Embeddings Model** to generate a vector embedding of their profile, which is stored in the database.
  2.  **Retrieval:** When a client requests a match, the system performs a high-speed **Vector Search** against the professional database using a similarity threshold.
  3.  **Reasoning:** The top candidates are sent to **NVIDIA's Llama 3.1 Nemotron Ultra 253b** model. This LLM analyzes the nuances of the client's goals against the professional's expertise to select the absolute best match.
- **Output:** Returns the matched professionals along with a natural language explanation generated by the LLM, telling the user exactly _why_ this match was made.

### 3. API Gateway for Mobile

Serves as the backend for the React Native mobile application.

- **Endpoints:**
  - `/api/auth`: Handles secure user sessions.
  - `/api/me/healthkit`: Receives and aggregates encrypted health metrics.
  - `/api/chat`: Manages real-time conversations between users and professionals.
- **Security:** Implements strict CORS policies and token-based authentication to protect user data.

### 4. Security

- **Supabase RLS:** Database policies ensure professionals can _only_ access data for their assigned clients.
- **SSR Auth:** Authentication is handled server-side using `@supabase/ssr` for maximum security and performance.
- **Middleware:** Protected routes prevent unauthorized access to admin and professional areas.

## 📂 Project Structure

The project leverages the Next.js App Router for a modern, nested layout architecture:

```
nextjsapp/
├── app/
│   ├── api/                 # Backend API Routes (Mobile & Web)
│   │   ├── me/              # User-centric endpoints (Match, Health)
│   │   └── professionals/   # Professional-centric endpoints
│   ├── dashboard/           # User Web Dashboard
│   ├── professionals/       # Professional Portal (Clients, Plans)
│   └── admin/               # Platform Administration
├── lib/                     # Shared Logic & Type Definitions
│   ├── supabase.ts          # Client-side Supabase client
│   └── supabaseServer.ts    # Server-side Supabase client (Admin access)
├── migrations/              # SQL Database Schemas
└── public/                  # Static Assets
```

## Getting Started

1.  **Install Dependencies:**

    ```bash
    npm install
    ```

2.  **Environment Setup:**
    Create a `.env` file with your Supabase credentials:

    ```env
    NEXT_PUBLIC_SUPABASE_URL=your_url
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key
    SUPABASE_SERVICE_ROLE_KEY=your_key
    NVIDIA_API_KEY=your_key
    ```

3.  **Run Development Server:**
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) to view the platform.
