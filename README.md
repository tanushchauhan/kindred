## Overview

The **Kindred Web Platform** serves two critical roles:

1.  **The Professional Portal:** It's a dashboard for personal trainers and nutritionists to manage clients, view health data, and personalized wellness plans.
2.  **The Backend:** It's based off Next.js and Supabase and links to the mobile app, handles authentication, and keeps track of health data.

---

## Technical Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Database & Auth:** Supabase (PostgreSQL + Auth)
- **Styling:** Tailwind CSS v4
- **Deployment:** Coolify
- **Security:** Row Level Security (RLS) + Server-Side Auth

---

## Key Features & Implementation

### 1. Professional Dashboard

- **Client Management:** Professionals can view their list of matched clients (`/professionals/clients`).
- **Health Insights:** Visualizes health data (steps, calories, macros) that gets synced from clients' Apple HealthKit via the mobile app.
- **Plan Creation:** Tools to assign specific exercise and nutrition plans to clients.
- **Direct Messaging:** Integrated chat to communicate with clients, answer questions, and provide feedback in real-time. Can happen between multiple professionals and their client.

### 2. The Matching Engine (`/api/me/match`)


- **The Pipeline:**
  1.  **Ingestion:** When professionals update their bios, a Supabase edge function triggers **NVIDIA's Embeddings Model** to generate a vector embedding of their profile, which is stored in the database.
  2.  **Retrieval:** When a client requests a match, the system performs a vector search against the professional database.
  3.  **Reasoning:** The top candidates are sent to NVIDIA's Llama 3.1 Nemotron Ultra 253b model. This LLM analyzes the nuances of the client's goals against the professional's qualifications to select the absolute best match.
- **Output:** Returns the matched professionals along with a natural language explanation generated by the LLM, telling the user why this match was made.

### 3. API Gateway for Mobile

This is the backend for the React Native mobile application.

  - `/api/auth`: Handles secure user sessions.
  - `/api/me/healthkit`: Receives and aggregates encrypted health metrics.
  - `/api/chat`: Manages real-time conversations between users and professionals.

### 4. Security

- **Supabase RLS:** Database policies ensure professionals can only access data for their assigned clients.
- **SSR Auth:** Authentication is handled server-side using `@supabase/ssr`.
- **Middleware:** Protected routes prevent unauthorized access to admin and professional areas.

## Getting Started

1.  **Install Dependencies:**

    ```bash
    npm install
    ```

2.  **Environment Setup:**
    Create a `.env` file with your Supabase credentials:

    ```env
    NEXT_PUBLIC_SUPABASE_URL=your_url
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key
    SUPABASE_SERVICE_ROLE_KEY=your_key
    NVIDIA_API_KEY=your_key
    ```

3.  **Run Development Server:**
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) to view the platform.
